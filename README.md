# LibraryDesk

Навчальний проєкт з дисципліни «Конструювання програмного
забезпечення». Варіант № 2: каталог бібліотеки та видача книжок.

## Склад рішення

- LibraryDesk.Core — логіка предметної області (бібліотека класів)
- LibraryDesk.App — консольний застосунок (введення, виведення)

## Вимоги

.NET SDK 8.0 або новіший (використовується 9.0), Git.

## Складання та запуск

    dotnet build
    dotnet run --project LibraryDesk.App

## Стандарт кодування

Правила описано у файлі CODING_STANDARD.md і закріплено
в .editorconfig. Перевірка: dotnet format --verify-no-changes
