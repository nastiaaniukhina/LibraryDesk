# Журнал архітектурних рішень

## ЖР-001. Окремий домен без паралельної моделі Lending

Попередню реалізацію Lending перенесено до `labs/LibraryDesk.Labs`, щоб основна модель видач не дублювала стару.

## ЖР-002. Напіввідкритий інтервал прострочення

На момент `DueAt` повні календарні дні прострочення дорівнюють нулю. Розрахунок виконується за календарними датами.

## ЖР-003. JSON як локальне сховище

JSON відповідає межам системи й не потребує серверної бази даних. Репозиторій ізолює деталі серіалізації від домену.

## ЖР-004. Доменні винятки для заборонених переходів

Порушення правил стану сигналізується доменними винятками; некоректне консольне введення перевіряється парсерами на межі застосунку.

## ЖР-005. Округлення лише підсумку

Грошові значення округлюються до двох знаків через `AwayFromZero` лише після підсумовування.

## ЖР-006. Журналювання на межі сценарію

Сервіси не залежать від конкретного механізму логування. `ScenarioRunner` фіксує початок, завершення та очікувані помилки.
