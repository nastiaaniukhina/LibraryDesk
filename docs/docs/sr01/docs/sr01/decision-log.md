# Журнал архітектурних рішень

## ЖР-001. Момент округлення грошових значень

- **Дата:** дата ухвалення рішення.
- **Контекст:** політики округлюють грошові значення для кожної позиції, тоді як метод `Calculate` округлює загальну суму.
- **Варіанти:** округлення кожної позиції окремо або округлення лише загального результату.
- **Рішення:** округлювати лише загальну суму відповідно до правила D-12.
- **Наслідки:** політики повертають неокруглені значення. Потрібно оновити тести `StudentFeePolicyTests`.
- **Статус:** прийнято.

## ЖР-002. Кінець періоду видачі

- **Дата:** дата ухвалення рішення.
- **Контекст:** умова `now <= due` у методі `Loan.MarkOverdue` не відповідає напіввідкритому інтервалу.
- **Варіанти:** замінити `now <= due` на `now < due` або залишити поточну умову як виняток.
- **Рішення:** використовувати `now < due`. У момент `DueAt` видача вже вважається простроченою.
- **Наслідки:** потрібно оновити тести та описати правило в `docs/model.md`.
- **Статус:** прийнято.
