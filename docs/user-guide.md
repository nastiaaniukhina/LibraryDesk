# Посібник користувача LibraryDesk

## Запуск

У корені репозиторію виконайте `dotnet run --project LibraryDesk.App`. Для створення демонстраційних даних виконайте `dotnet run --project LibraryDesk.App -- seed`. Файл даних зберігається у `data/library.json`, журнал — у `data/scenario.log`.

## Робота з меню

Після запуску оберіть пункт меню та введіть потрібний номер видачі, ID читача, ISBN або дату `yyyy-MM-dd`.

- Видати книжки: введіть номер бронювання. Дозволено лише для `Reserved`.
- Прийняти повернення: введіть номер видачі. Для прострочених позицій система покаже пеню.
- Скасувати бронь: доступно лише для `Reserved`.
- Пошук: введіть ID читача або ISBN.
- Звіт боржників: введіть дату у форматі `yyyy-MM-dd`.

## Повідомлення про помилки

| Повідомлення / ситуація | Причина | Дія |
|---|---|---|
| Некоректний номер | ID не є додатним цілим числом | Введіть номер повторно |
| Видачу не знайдено | У сховищі немає такого ID | Перевірте номер |
| Заборонений перехід | Поточний стан не дозволяє операцію | Перевірте стан видачі |
| Некоректна дата | Дата не відповідає `yyyy-MM-dd` | Введіть дату повторно |
| Помилка роботи з файлом | Проблема читання або запису JSON/журналу | Перевірте доступ до папки `data` |

## Резервна копія

Перед копіюванням зупиніть застосунок. Скопіюйте `data/library.json` у безпечне місце. Відновлення виконується поверненням копії у папку `data`.
