## 1. Межі системи і словник

| Входить | Свідомо не входить |
| --- | --- |
| облік читачів, книжок, видач | бази даних, мережеві сервіси |
| видача книжок і прийом повернення | оплата штрафів через банк |
| розрахунок плати і пені за прострочення | інвентаризація примірників |
| зміна стану видачі за таблицею переходів | облік прав доступу працівників |
| пошук видач і звіт «боржники на дату» | графічний інтерфейс, веб |
| зберігання у JSON | резервне копіювання в хмару |
